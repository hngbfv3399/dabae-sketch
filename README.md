# 담빵메모지 (Dabae Memo)

> "갑자기 떠오른 아이디어를 바탕으로 자유롭게 메모를 남기고 노는, 아기자기한 감성의 실시간 익명 메모판입니다."  
> 이 프로젝트는 성능 수치에 대한 심도 있는 고찰 없이, 무언가 생각나서 즉흥적이고 순수하게 재미로 바로 만든 토이 프로젝트입니다.

---

## 🎨 주요 기능

1. **아기자기한 4가지 모양의 메모지**
   * 사각형, 원형 뿐만 아니라 개성 있는 **사과**🍎 모양과 **하트**❤️ 모양 메모지를 지원합니다.
   * 사과와 하트는 SVG 벡터 라인을 따라 그림자가 생기도록 CSS `filter: drop-shadow` 효과를 적용했습니다.
2. **랜덤 파스텔 컬러 배치**
   * 어두운 색상은 배제하고, 눈이 편안하고 예쁜 8가지 파스텔톤 컬러 중 하나가 메모지 추가 시 랜덤하게 부여됩니다.
3. **영구 고정(Read-Only) 메모**
   * 등록 전 제어 바에서 닉네임과 내용을 미리 적어 붙이는 방식입니다.
   * 한번 칠판에 붙인 메모지의 글은 **다시는 수정할 수 없으며**, 오직 이동 및 삭제만 가능하여 익명 담벼락의 낙서 감성을 연출합니다.
4. **자유로운 드래그앤드롭**
   * HTML5 Pointer Events를 사용하여 마우스뿐만 아니라 모바일 기기의 터치 드래그로도 메모지를 부드럽게 움직일 수 있습니다.
   * 메모지 생성 시 ID 해시값을 바탕으로 `-3도 ~ 3도` 사이의 회전각이 자연스럽게 랜덤 부여됩니다.
5. **Cozy한 일기장 테마**
   * 따뜻한 크림빛 색상(#FDFBF6)의 배경 위에 옅은 브라운 격자 도트(Dot Grid) 무늬가 깔려 있습니다.
   * 가로 3000px, 세로 2000px의 대형 칠판이며, 최초 접속 시 자동으로 화면 한가운데로 스크롤이 맞춰집니다.

## 🛠 사용된 기술 및 선택 이유

* **Next.js (v16 App Router)**
  * 현대적인 React 풀스택 프레임워크로, 파일 기반 라우팅 및 폴더 구조화가 직관적이어서 신속한 레이아웃 구현을 위해 선택했습니다.
  * 구글 폰트(`Noto Sans Korean`)를 내장 폰트 시스템을 통해 자모음 분리 현상 없이 매끄럽게 로드합니다.
* **Convex**
  * 실시간 동시성 및 다중 사용자 화면 동기화(Multiplayer)를 가장 쉽고 빠르게 구현하기 위해 채택했습니다.
  * 복잡한 WebSocket 소켓 서버 개설이나 API 통신 코드 작성 없이, 리액티브 쿼리(Reactive Queries)를 사용해 여러 브라우저 탭 간에 실시간 메모 위치 동기화를 즉각 처리합니다.
* **Tailwind CSS (v4)**
  * 유틸리티 퍼스트 CSS 프레임워크로, 별도의 스타일 시트 파일을 번거롭게 오가지 않고 인라인 클래스명만으로 아기자기한 글래스모피즘(Glassmorphism) 컨트롤 바와 정밀한 여백 조정을 빠르게 구현할 수 있어 선택했습니다.

## 🤖 개발 방식 (Human-AI Collaboration)

이 프로젝트는 **사람의 기획 및 디렉팅**과 **AI(Antigravity)의 코드 작성**을 결합한 페어 프로그래밍 방식으로 개발되었습니다.

* **사람의 역할 (기획 및 명령)**
  * "익명으로 적을 수 있는 실시간 메모판"의 핵심 컨셉 구상.
  * 사과, 하트, 원, 네모 모양의 메모지 형태 및 다크 모드를 배제한 밝은 파스텔톤 무작위 컬러 배치 아이디어 설계.
  * "한번 붙인 메모지는 다시 수정 불가능하게 고정"하는 동작 룰 수립.
  * "소곤소곤게시판"에서 "담빵메모지"로의 브랜딩 리다이렉션, 버전 텍스트 제거 및 서버 연결 상태 텍스트("서버 상태: 정상/문제있음") 가이드라인 설계.
  * 칠판 하단 제어 바의 높이를 기본 여백보다 5px만큼 더 띄우도록 지시하는 등 미세한 비주얼 피드백 제공.
* **AI의 역할 (코드 구현 및 검증)**
  * Next.js 프로젝트 세팅 및 Tailwind CSS v4 테마 연동.
  * SVG 패스 기반의 비정형 사과/하트 카드 레이아웃 정교화 및 텍스트 자동 개행 구현.
  * HTML5 Pointer Events 기반의 60fps 무지연 드래그앤드롭 이벤트 핸들러 빌드.
  * Convex 클라우드 연결 부재 시에도 LocalStorage로 즉시 동작하는 오프라인 샌드박스 듀얼 모드 구현.
  * 타입스크립트(TypeScript) 컴파일 검증 및 린터(Linter) 최적화 수행.

## 🚀 로컬 실행 방법

### 1. 의존성 설치
```bash
npm install
```

### 2. Next.js 개발 서버 실행 (기본 로컬 모드)
환경 변수 설정이 없어도 브라우저 캐시(`localStorage`)를 이용해 즉시 메모판을 체험할 수 있습니다.
```bash
npm run dev
```
브라우저를 열고 `http://localhost:3000`에 접속합니다.

### 3. Convex 서버 구동 (실시간 멀티플레이어 모드)
실시간 다른 사람들과의 동기화를 테스트하려면 새로운 터미널에서 아래 명령어를 실행하여 DB를 연동하세요.
```bash
npx convex dev
```
* 최초 실행 시 Convex 가입/로그인 브라우저 창이 열리며, 완료 시 `.env.local` 파일이 자동 생성됩니다.
* 환경 변수 주입을 위해 `npm run dev` 서버를 종료 후 재시작합니다.
